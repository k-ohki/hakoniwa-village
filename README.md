# 箱庭の村 (Hakoniwa Village)

**▶ 遊ぶ: https://k-ohki.github.io/hakoniwa-village/**

単一HTMLファイル（`index.html`、`src/` からビルド）で動く、等角投影の小さな町の生活シミュレーション。ブラウザで開くだけで動きます。
GitHub Pages で公開しています（`main` への push で `.github/workflows/pages.yml` が `index.html` だけを配信）。Claude Artifact としても公開でき、その場合は `index.html` をそのまま公開します（`sample` 機能を宣言）。

> **Google Fonts・外部CDNは禁止。外部通信は Claude API のみ。APIキーはリポジトリに入れない。** フォントはシステムフォントのみ。`npm run check` で自動検出します。

## 開発

```sh
npm run build   # src/ → index.html を生成
npm run check   # 外部リソース禁止・秘密情報（全履歴）・構文・ビルド最新かを検査
npm run verify  # build + check
npm test        # check + ブラウザのテスト一式（要 Playwright）
npm run smoke   # 起動・API キー経路（API はモック）・一人称モード
npm run sim     # 住人を3日分動かし、生活の行動が一通り起きるか
npm run test:build  # 設計図の検査・2階建ての建物の配置・階段で2階へ行けるか・撤去
npm run visual -- index.html out/ base/  # 決まった視点のスクリーンショットを撮り、base/ と比べる
```

- 編集は `src/`（`index.template.html` / `styles.css` / `js/NN-*.js`）で行い、`index.html` は直接編集しない
- 開発ルールは `CLAUDE.md`、CI は `.github/workflows/ci.yml`

## Claude API キー

GitHub Pages 版で Claude を使うには、「町」→「Claude API」に自分の [Anthropic API キー](https://console.anthropic.com/) を入れます。

- キーはそのブラウザの localStorage にだけ保存され、`api.anthropic.com` へ直接送られます。サーバーやリポジトリには残りません
- 共用の端末では入れないでください。不要になったら「キーを削除」、心配なら Console でキーを無効化
- 住民の会話は Haiku 5.5、建物の設計は Sonnet 5.5 を使います。神の声の解釈は Opus 5.5（既定）／Sonnet 5.5／Haiku 5.5 から選べます。料金は各自のキーに課金されます
- キーが無い時は従来どおりオフラインの簡易解釈で動きます。Claude Artifact 上では host の `sample` を使うため、この欄は出ません

## 主な機能

- **自律する住民**: 12人＋猫が、欲求（エネルギー・空腹・社交・楽しさ・トイレ・清潔）に基づく効用AIで行動。関係性・記憶・気分・天気・昼夜・曜日・お祭りあり
- **大きな町**: 昔からの村に加えて、学校（2階建て: 教室・昇降口・図書室・音楽室）、デパート（3階建て: 食品・洋服・おもちゃとレストラン）、校庭の遊具、新しい家2軒
- **仕事と学校**: 子どもは平日に登校して授業と給食、先生は授業、店員はデパートで働く。お店や施設には営業時間がある
- **階の切りかえ**: 内観で「◯階」ボタンを押すと、上の階を見られる
- **神の声**: テキスト入力で住民の行動に影響。Claude（`sample`）が解釈。使えない時はキーワードによるオフライン解釈
- **建物の生成**: 神の声から Claude が設計図を作り、検証（`sanitizeSpec`）して配置。小物（部品の組み合わせ）から、部屋・家具・階段のある最大3階建ての建物まで。町の家と同じしくみで組み立て、住人が中に入って使う。永続化
- **場面の会話**: お店の店員と客、給食、授業、釣り、立ち話などのよくあるやり取りを英日対訳のカードと吹き出しで表示。相手が居合わせない時は役割つきの台詞で再生。住人カードの「会話を聞く」ですぐ再生
- **英語学習モード**: 生活英語、家の中が見える断面表示、ラベル表示切替、フレーズ帳、音声読み上げ
- **一人称モード**: 任意の住民を操作。自作 WebGL レンダラー（外部ライブラリなし）
- **町のブラウザ保存**: 自動保存（10秒ごと／閉じる時）。時刻・天気・住民の状態・建物・町の歩みを復元。「町」ボタンから手動保存・リセット
- **町の成長**: 約1日ごとに住民の願いや出来事（お祭り・虹など）を起点に、小物が増える／既存の建物が変化。AI利用時は Claude が設計、不可時は7種のカタログ（ブランコ・花だん・読書ベンチ・かかし・ピクニックテーブル・ちょうちん灯・水のみ場）

   - 2回目（真因）: 特定角度で、家の床の板が家より後に描かれ家を覆っていた（描画順の循環）。床など低く広い板を別パスで先に描画して解消
8. 町のブラウザ保存と、住民の願い・出来事による町の成長を追加
9. GitHub リポジトリへ移行（クラウドセッションで開発を続けるため）
10. Google Fonts を廃止してシステムフォントのみに。`src/` 分割・ビルド・検査・CI を整備
11. GitHub Pages で公開。各自の API キー（ブラウザ保存）で Claude を使えるように
12. 町と建物をデータ化。家も神の声の建物も同じ設計図から組み立てる方式に（複数階・家具カタログ・行動場所）。見た目は変えずに作り替え
13. 大きな町に拡張（30×24マス）。学校・デパート・住人6人を追加し、仕事・学校の時間割と曜日を導入。1日を5分に（広い町を歩けるように）。描画順の循環を解消
14. 住民の場面の会話（英会話学習）を追加。会話は Haiku、建物は Sonnet。固定の指示はキャッシュし、話題・口調・使用済みの書き出しを変えて同じ返答を避ける。生成した会話は保存して再利用
15. 東の端の滝を廃止。昼（5〜22時）の時計を 1/3 の速さにしてゆっくり眺められるように（夜はそのまま。1日 約12分）。住人の動きの速さは変えない

## 実装メモ

- 描画: Canvas2D の箱ベース等角投影。位相ソート（`sep()`/`topo()`）。床など `whi.z<=0.2` で面積2.5以上の板は `topo` の外で先に描く
- 壁: カメラに近い側の壁は `prepBox` で低くカットし、内部が見える
- 町と建物: 地図は `TOWN`（`11-town.js`）、建物は設計図から `buildBuilding`（`09-builder.js`）で組み立て。家具カタログ（`08-furniture.js`）が行動場所を登録
- 神の声の建物: `sanitizeSpec` → `findSpot`/`canPlace`（連結性・入口チェック）→ `placeBuilding`。活動は `ACTS` に動的追加
- 複数階: 階ごとにタイルを持ち、階段のタイル同士をつなぐ。内観では選んだ階より上を描かず、その階の手前の壁だけ低く切る
- 保存キー（localStorage）: `hakoniwa-save-v1`（町）、`hakoniwa-builds`（建物）、`hakoniwa-book`（フレーズ帳）、`hakoniwa-lang`、`hakoniwa-labels`、`hakoniwa-api-key`・`hakoniwa-api-model`（Claude API）
- Artifact 制約: 外部CDN・Google Fonts 不可。three.js は使わず自前 WebGL。全体は IIFE 内

## 検証状況・既知の課題

- ヘッドレス Chromium（Playwright）で、回転角ごとの描画順、複数日シミュレーション、保存・復元、オフライン経路を確認済み
- 未検証: 実機 iPad での操作感、Claude 利用経路（神の声／住民との会話／建物設計／町の成長のAI版）。サンドボックスでは `sample` が使えずオフライン経路のみ試験
- 描画順: 複数の軸で向きが食い違う組（画面上で重ならない）には順番を付けないことで循環を解消。循環が残った時も、その循環の中だけで切る
- 性能: 町は昔の村の約1.5倍の描画時間（ヘッドレス環境で約30ms/フレーム）。実機での確認はまだ
